# Security Policy

## Scope

This is a public development repository for an experimental trading system. Treat all exchange credentials, account identifiers, host details, database exports, operational logs, and real trading records as sensitive.

Do not submit secrets in issues, pull requests, commits, fixtures, screenshots, or documentation.

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability. Use GitHub's private vulnerability reporting feature when it is available for this repository. If it is unavailable, contact the repository owner through the GHolmesDesigns GitHub profile and do not include credentials or other live secrets in the initial report.

## Operational boundary

The public repository must not contain production trading credentials or production deployment authority. Live activation requires separately managed credentials, an explicit confirmation, and the application's independent safety gates.
