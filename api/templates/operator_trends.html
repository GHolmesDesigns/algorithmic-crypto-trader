Reading these charts

  • Bars are drawn in one neutral ink. Green and red stay reserved for system health, so a tall bar is a count, not a verdict.
  • A count of zero is written as 0. A chart that could not be read says Not available, and a chart with no producer says Not started and why. Neither draws an axis.
  • Every chart has a table with the same counts. In the discrepancy and refusal tables, each period links to its records.
  • These counts come from the database and survive restarts. The dashboard's reconciliation counters cover only the running process.
